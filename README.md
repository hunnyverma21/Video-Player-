# Nova Video Player

A lightweight, browser-based local video player.

## Run
1. Extract `Nova-Video-Player.zip`.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Select **Open video** and choose a video stored on your device.

## Features
- Local video file playback (the file stays in your browser; it is not uploaded)
- Play/pause, 10-second rewind and forward
- Seek bar and playback time
- Volume control and playback speed (0.5x–2x)
- Fullscreen and Picture-in-Picture where supported
- Keyboard shortcuts: Space = play/pause, Left/Right = seek, F = fullscreen, M = mute

No installation or server required.
